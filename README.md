
# Proyecto EDA UTEC 2026-2

## Sistema de comercio electrónico

Pipeline de procesamiento de eventos de comercio electrónico
utilizando estructuras de datos y algoritmos avanzados.

**Curso:** Estructuras de Datos y Algoritmos  
**Programa:** Maestría en Ciencia de Datos e IA - UTEC  
**Dataset:** REES46 - eCommerce Behavior Data  
**Lenguaje:** Python 3.12

## Objetivo

Diseñar, implementar y evaluar un pipeline integrado
capaz de procesar hasta 10 millones de eventos.

## Arquitectura

0. Ingesta y buffer - FIFO
1. Preprocesamiento - Ordenación y búsqueda binaria
2. Priorización - Heap
3. Almacenamiento - Hash Table, CSR y LRU
4. Indexación principal - B+Tree
5. Índice multidimensional - KD-Tree y KNN exacto
6. Filtrado probabilístico - Bloom Filter y Count-Min Sketch
7. Similitud aproximada - MinHash, LSH y HNSW
8. Grafo de co-compra - PageRank y Louvain
9. Servicio - Top-K y dashboard

Se realizarán experimentos con tamaños de:

- 1,000 eventos

- 10,000,000 eventos
